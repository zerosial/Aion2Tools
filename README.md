## v1.9.2 — 전투 중 멈춤 · 캡처 안정화

- **전투 중 미터가 멈추던 현상 수정** — 알 수 없는 대상이거나 네트워크에서 패킷 일부가 유실되는
  상황에서 DPS 갱신이 멈춰 전투가 끊겨 보이던 문제를 바로잡았습니다. 막힘이 생겨도 스스로 다시

- **캡처가 멈추던 현상 자동 복구** — 절전에서 깨어나거나 네트워크가 바뀌어 패킷 수집이 끊기면
  자동으로 다시 연결해 복구합니다.
- **문제 발생 시 자동 진단** — 이름이 숫자로 보이거나 캡처가 멈추는 등 이상이 생기면 원인 파악용
  정보가 자동으로 전송되어 더 빠르게 수정할 수 있습니다.

## v1.9.1 — 보스 HP 정확도 · 안정성 개선

- **보스 HP % 정확도 개선** — 보스 등장 시 실제 최대 HP를 반영해, 전투 도중 합류해도 HP 바가

## v1.9.0 — 보스 HP 표시 · 타겟 인식 개선

- **보스 처치 후 HP 바가 ~1%에서 멈춰 보이던 현상 개선** — 보스가 죽는 순간의 마지막 HP
  값이 0 직전(약 0.7~1%)에서 끊겨 바가 다 닳지 않은 것처럼 보였습니다. 처치로 판정되면
  잔여 HP를 0%로 맞춰 빈 바로 표시합니다.
- **"타겟 인식 실패" 개선** — 전투 시작 신호를 놓쳐 타겟이 안 잡히면 보스 HP 바·딜 행이
  표시되지 않는 경우가 있었습니다. 이제 보스에게 첫 유효타가 들어가는 순간 타겟을 자동으로
  잡습니다(이미 잡힌 타겟은 덮지 않음).

## v1.8.1 — 조회 설정 즉시 반영 · 통신 안정화 · UI 다듬기

- **조회 설정 반영 속도 개선** — 웹 관리 설정(조회 On/Off)이 미터기에 반영되는 시간을
  최대 60초에서 **10초**로 단축했습니다. Off 상태에서는 보유 중인 DB 정보만 표시합니다.
- **서버 통신 안정화** — 일부 환경에서 설정 조회·오류 자동 보고 전송이 지연되거나

  과부하가 걸리던 문제를 수정했습니다. 이제 자동으로 중단하고 오류를 보고합니다.
- **창 크기 고정 개선** — 조회 모드와 DPS 모드 전환 시 창 크기가 줄어들거나 늘어나지 않고
  사용자가 정한 고정 크기로 일정하게 유지됩니다.
- **검색 영역 확대** — 이름 직접 검색창과 돋보기 아이콘을 키우고 가로 폭을 190px로
  넓혔습니다.
- **토글 잠금 UI 정리** — 자물쇠(🔒)·노란 링 강조를 제거해 미니멀하게 다듬고, 수동 토글
  화면 고정을 30초→**10초**, 전투 종료 후 조회 화면 복귀 쿨다운을 30초→**20초**로
  단축했습니다.

## v1.8.0 — 안정성 개선 및 편의 기능 추가

- **바탕화면 아이콘 추가 및 설치 편의성 개선** — 설치 시 바탕화면에 실행 바로가기 아이콘을 추가하여 접근성을 한층 더 높였습니다.
- **업데이트 프로세스 최적화 및 자동 재실행 보강** — 업데이트 완료 후 백그라운드 스크립트를 통한 무중단 자동 재실행 로직을 보완하고, "리소스 부족" 오류 및 불필요한 콘솔 창이 노출되지 않도록 개선했습니다.
- **작업표시줄 고정 바로가기 복구 개선** — 버전 업데이트 이후 작업표시줄 고정 아이콘이 깨지거나 실행이 불가능해지는 현상을 방지하도록 바로가기 파일 자동 복구 로직을 보강했습니다.
- **프로그램 명칭 단일화 및 관리자 권한 예외 대응** — UI 및 런타임 상의 프로그램 이름을 `Aion2Cal`로 완전히 단일화했으며, 최초 실행 시 UAC 관리자 권한 승인을 거부하더라도 안내 후 안전하게 종료되도록 방어 코드를 적용했습니다.
- **전투 통계 및 일부 UI 반응성 최적화** — 집계 데이터 전송 시 안정성을 극대화하고, 화면 크기 고정 및 랙 현상 등 전반적인 조작 감도를 향상했습니다.

### v1.7.11 신규

- **티어 조회 반응성** — 조회·지원 시 티어 자리에 스켈레톤을 띄우고, 잠시(약 5초) 안에 최신 정보가 오면 그대로, 늦어지면 보유 중인 정보를 먼저 보여준 뒤 자연스럽게 최신화합니다. 창이 멈추지 않습니다.
- **조회·지원 스킬/스티그마 표기·레벨** — 파티 지원이 오면, 미리 선택해 둔 직업별 스킬·스티그마의 표기와 레벨이 행에 함께 표시됩니다. (조회·지원 헤더의 **"스킬"** 버튼에서 표시할 항목을 선택 — 기본은 모두 해제, 선택값은 저장됩니다.)

### 메인 통합 · UI 개선

- **파티 지원/조회를 메인 창으로 통합** — 떠다니던 별도 파티지원 창을 없애고, 비전투(idle) 화면의 조회·지원 리스트로 합쳤습니다. 각 항목에 **티어**가 표시되고, 클릭하면 https://cielui.com 통계 페이지가 열립니다.
- **창 크기 고정·동기화** — 우하단 코너 드래그로 폭·높이를 정하면 조회·전투(DPS) 화면이 같은 크기로 고정됩니다. 내역이 많으면 스크롤로 확인합니다. (설정 초기화 전까지 유지)
- **보스 HP 바** — 보스 체력이 줄면 막대도 함께 줄어들어(이전엔 % 숫자만 변경) 실제 체력 감소가 한눈에 보입니다.
- **불필요 기능 정리** — 수동 업로드 버튼 제거(설정의 자동 업로드로 대체).

### 안정성 · 반응성 개선

- **전투 중 멈춤 현상 수정** — 특정 전투 도중 DPS 집계가 갑자기 멈추던 현상을
  해결했습니다. 예기치 못한/변종 패킷에도 집계 루프가 끊기지 않도록 방어했습니다.
- **파티원 DPS 캐치 수정** — 파티 전투에서 본인 기록만 보이고 파티원 기록이 누락되던
  현상을 수정했습니다. (번들 패킷의 경계 처리 보강)
- **오류 자동 보고(관측성)** — 미터기에서 발생하는 모든 예외/이상을 백그라운드로
  자동 수집·전송해, 문제를 더 빠르게 잡아 고칠 수 있게 했습니다. (개인정보는 마스킹)
- **정보보기/지원 시 멈춤 제거** — 티어를 가져오는 동안 미터기 창이 3~4초 멈추던
  현상을 해소했습니다. 이제 창은 즉시 뜨고, 티어는 도착하는 대로 자리에 채워집니다
  (그 사이 스켈레톤 표시).
- **지원 카운트다운 바 부드럽게** — 20초 카운트다운 막대가 끊겨 보이던 것을
  매끄러운 애니메이션으로 교체했습니다.
- **작업표시줄 아이콘** — 트레이뿐 아니라 작업표시줄에도 미터기 아이콘이 표출됩니다.
- **설치 안내 한글화 + 동의 페이지** — 설치 시 한글 안내 페이지가 표시됩니다. 수집·전송되는 정보(오류 자동 보고, 본인 및 파티원의 전투 기록)와 웹사이트(https://cielui.com)를 상세히 고지하며, 설치는 관리자 권한 없이 사용자 영역에 진행됩니다(실행 시 자동 권한 요청).
- **보스 처치(클리어) 여부 기록** — 전투 기록에 보스를 실제로 처치했는지 여부를
  함께 전송합니다. 보스의 잔여 체력이 0에 도달했는지로 판정하므로, 트라이/전멸과
  실제 클리어를 정확히 구분합니다. (https://cielui.com 의 클리어 기록·뱃지가 정확해집니다.)
- **전투 기록 중복 업로드 방지** — 같은 전투가 여러 트리거로 두 번 이상 전송되던
  여지를 막아, 동일 전투는 한 번만 기록되도록 했습니다.
- **통계 업로드 on/off (설정)** — 설정 패널에 「전투 통계 업로드」 토글을 추가했습니다.
  끄면 내 전투 기록이 https://cielui.com 통계로 전송되지 않습니다. (오류 자동 보고는
  진단 목적으로 이 설정과 무관하게 동작합니다.) 설치 시 고지된 대로 기본은 켜짐입니다.

### 신규 — 미터기 메인 창 모드 자동 전환

미터기가 전투 상태와 조회에 따라 두 모드를 자동으로 오갑니다:

| 상태 | 메인 창 | 비고 |
|---|---|---|
| 전투 중 (`isInCombat=true`) | **DPS 모드** | 기존 미터 표 · 타겟 정보 · 전투 타이머 |
| 전투 종료 직후 30초 동안 | **DPS 모드 유지** | 즉시 사라지면 후반 기록 확인 못 함 |
| 그 외 (idle / 30초 cooldown 종료 후) | **정보 조회 모드** | 인게임에서 캐릭터 정보 조회한 결과 누적 리스트 |
| **전투 중 새 캐릭터 조회 시** | **약 10초간 정보 조회 모드로 전환 후 DPS 복귀** | DPS는 백그라운드에서 계속 집계. 방금 조회한 캐릭터를 잠깐 확인하고 자동으로 DPS로 돌아옴 |

**좌상단 토글 버튼** — DPS/조회 화면을 직접 전환할 수 있습니다. 수동으로 누르면 그
화면이 **30초간 고정**(자동 전환 중단, 🔒 표시)되며, 30초 후 자동으로 재개됩니다
(전투 중이면 DPS, 아니면 조회 화면).

`useMeterMode` hook이 상태 머신을 관리합니다 (전투 edge로 dps 복귀, 전투 중 새 조회는
10초 info bounce, 수동 토글 30초 잠금).
